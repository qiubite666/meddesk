# MedDesk · 工具箱与文件存储

> **一句话**：工具箱是一组**纯本地计算**的小工具（不联网、不上传），文件存储（WebDAV）是把你自己的网盘挂进 MedDesk 的**后端代理通道**（凭据加密存本地、服务端不留存）。
>
> **结论先行**：计算器的数据**永远不离开浏览器**；文件存储的**凭据**会离开浏览器，但只到**你自己部署的 MedDesk 服务端**，且**不落盘、不记日志**。

## 1. 模块结构

### 1.1 前端

```
web/assets/js/
├── tools.js                  # 工具箱容器：首页 + 统一外壳 + 表单/结果构件（平台层）
├── tool-unit-price.js        # 单价计算器     tools/unit-price  order 10
├── tool-loan.js              # 贷款计算器     tools/loan         order 20
├── tool-fuel.js              # 油耗计算器     tools/fuel         order 30
├── tool-convert.js           # 单位换算器     tools/convert      order 40
└── webdav.js                 # 文件存储：设置页配置区 + 文件浏览路由（id = files）
```

分层约定（工具箱内部）：

```
注册层  register(spec)        声明工具的元信息（id / 标题 / 图标 / 分类 / 排序）
  ↓
外壳层  mount(view, toolId)   面包屑「工具箱 / 分类 / 工具名」+ 分类导航 + 标题 → 返回内容容器
  ↓
构件层  field / select / resultCard / parseNum / fmtNum
  ↓
工具页  自己的输入层 → 计算层（纯函数）→ 渲染层（只写 DOM）
```

三条铁律：

1. **工具之间零耦合**——不互相 import、不共享可变状态，只依赖 `MD.tools` 与 `MD.ui`。
2. **计算层是纯函数**——输入 `{...}` 输出 `{...}`，不碰 DOM，便于推演与自查。
3. **任何不可展示的数值一律收敛为「—」**——界面上绝不出现 `NaN` / `Infinity` / `undefined`。

### 1.2 后端

```
internal/webdav/              # WebDAV 代理：凭据校验、SSRF 防护、路径边界、请求转发
挂载点：internal/server/router.go → /api/v1/webdav/*
```

> 后端**不做**任何持久化：没有 WebDAV 相关的表、没有配置文件、没有缓存键。

## 2. 路由与导航约定

| 路由 id | 标题 | 分组 | parent | hidden | 说明 |
|---|---|---|---|---|---|
| `tools` | 工具箱 | 工具箱 | — | 否 | 首页：按分类展示工具卡片 |
| `tools/unit-price` | 单价计算器 | 工具箱 | `tools` | **是** | 子路由，不进侧栏 |
| `tools/loan` | 贷款计算器 | 工具箱 | `tools` | **是** | 子路由 |
| `tools/fuel` | 油耗计算器 | 工具箱 | `tools` | **是** | 子路由 |
| `tools/convert` | 单位换算器 | 工具箱 | `tools` | **是** | 子路由 |
| `files` | 文件存储 | 工具箱 | — | 否 | WebDAV 文件浏览 |

- **子路由不进主导航**：`hidden: true` 的路由只出现在工具箱容器内部（分类导航条 / 首页卡片），侧栏与移动端底部 Tab 看不到它们。
- **父项高亮**：子路由激活时，路由系统按 `parent` 反向命中，侧栏「工具箱」保持高亮。
- **注册顺序无关**：首页按 `order` 升序、`title` 字典序排列；晚加载的工具脚本注册后，若首页正打开会自动重绘。
- **没有工具时**：首页显示空态「暂无可用工具」，不会白屏。

## 3. `MD.tools` 接口契约

> 由 `tools.js` 导出，是工具页唯一可依赖的公共面。签名与行为以本节为准。

| 函数 | 参数 | 返回 | 说明 |
|---|---|---|---|
| `register(spec)` | `spec` 见下表 | route 对象 | 注册一个工具子路由；参数无效（`id` 缺失 / `render` 非函数）直接抛 `TypeError` |
| `mount(view, toolId)` | `view` DOM 容器；`toolId` 短 id（`'unit-price'`，带 `tools/` 前缀亦可） | 内容容器（`.stack`） | 渲染面包屑 + 分类导航 + 标题区，返回供工具页填充的容器 |
| `field(opts)` | `{label, unit, value, placeholder, step, min, hint, onInput(num)}` | `{row, input, setError(msg)}` | 数字输入行；`onInput` 收到 `number\|null` |
| `select(opts)` | `{label, value, options:[{value,label}], hint, onChange(value)}` | `{row, select}` | 下拉选择行 |
| `resultCard(opts)` | `{title, tone, items:[{label, value, unit, strong}]}`，`tone ∈ ok/warn/danger` | card 元素 | 结果卡片；`strong: true` 的项放大加粗并跟随 `tone` 取色 |
| `parseNum(str)` | 任意字符串 | `number \| null` | 去逗号/空格后严格匹配数字（含科学计数法）；空串、非数字、`NaN`、`Infinity` 一律 `null` |
| `fmtNum(n, digits)` | 数字；小数位（默认 2） | `string` | 千分位 + 定点小数；非有限值返回 `'—'` |

`register(spec)` 的 `spec`：

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | ✅ | 短 id，实际路由 id = `'tools/' + id` |
| `title` | ✅ | 工具名（面包屑与卡片标题） |
| `subtitle` | — | 一句话说明 |
| `icon` | — | 图标名，缺省 `toolbox` |
| `category` | — | 分类名，缺省 `其他`；首批四个工具均为「计算工具」 |
| `order` | — | 排序值，越小越靠前 |
| `render(view)` | ✅ | 渲染函数，接收路由容器；内部应先调 `MD.tools.mount(view, id)` |

派生行为（由 `register` 自动补齐，工具页无需声明）：`parent = 'tools'`、`hidden = true`、`group = '工具箱'`。

最小示例：

```js
MD.tools.register({
  id: 'bmi',
  title: 'BMI 计算器',
  subtitle: '身高体重指数',
  icon: 'heart',
  category: '计算工具',
  order: 50,
  render: function (view) {
    var content = MD.tools.mount(view, 'bmi');
    var height = MD.tools.field({ label: '身高', unit: 'cm', onInput: paint });
    content.appendChild(height.row);
    // ... paint() 里用 MD.tools.resultCard 输出结果
  }
});
```

## 4. 四个计算器

> **共同点**：全部在浏览器本地完成，**零网络请求**；输入即时重算（无需点「计算」）；结果区带 `aria-live="polite"`，读屏软件可感知变化；所有文案用 `textContent` 写入，不拼接 `innerHTML`。

### 4.1 单价计算器 · `tools/unit-price`

**用途**：两个商品谁更划算（超市比价、囤货决策）。

| 输入项（商品 A / B 各一组） | 说明 |
|---|---|
| 价格（元） | ≥ 0；`0` 是合法值（赠品/凑单） |
| 数量 | 必须 > 0 |
| 单位 | 个 / 克 / 公斤 / 毫升 / 升 / 米 |

| 输出 | 说明 |
|---|---|
| 各侧单价 | `元/单位`，小数位按量级自适应（见下） |
| 结论 | 「A 更划算」/「B 更划算」/「两者单价相同」 |
| 差价 | 折算到同一基准单位后的差额 |
| 便宜幅度 | `差价 ÷ 较大单价 × 100%`，保留 1 位 |

要点：

- **公式**：`单价 = 价格 ÷ 数量`。
- **量纲折算**：只有同量纲才换算比较——`克 ↔ 公斤`（1 公斤 = 1000 克）、`毫升 ↔ 升`（1 升 = 1000 毫升）；异量纲（如 `个` vs `克`）**只按各自单位比较**，结果卡转 `warn` 并明确提示「仅供参考」。
- **小数位自适应**：≥1 保留 2 位、≥0.1 保留 3 位、≥0.01 保留 4 位、≥0.001 保留 5 位、更小保留 6 位——避免 `0.0033 元/克` 被四舍五入成 `0.00`。
- **相等判定**：相对误差 ≤ `1e-9` 视为相同。

边界行为：

| 情况 | 表现 |
|---|---|
| 未填写 / 只填一侧 | 该侧单价显示「—」；只填一侧时结论区展示已填侧单价并引导补另一侧 |
| 价格 < 0 | 该侧「价格不能为负数」，输入框标红 |
| 数量 ≤ 0 | 该侧「数量需大于 0」，单价显示「—」（**不是** `Infinity`） |
| 非数字字符 | 输入框即时提示「请输入有效数字」；空值不报错（视为未填写） |

### 4.2 贷款计算器 · `tools/loan`

**用途**：房贷/车贷月供与总利息，支持等额本息与等额本金。

| 输入项 | 说明 |
|---|---|
| 贷款金额（元） | 支持「万 / 亿 / w」后缀，如 `100万` = `1000000`；必须 > 0 |
| 年利率（%） | 留空或 `0` 视为**免息**；不能为负 |
| 贷款期限（月） | 取整，范围 `1 ~ 1200`（100 年） |
| 还款方式 | 等额本息（月供固定） / 等额本金（月供递减） |

| 输出（等额本息） | 输出（等额本金） |
|---|---|
| 月供（每期固定） | 首月月供 |
| 支付利息总额 | 每月递减 |
| 本息合计 | 末月月供 |
| 还款期数 | 支付利息总额、本息合计 |

**还款计划表**：按月 / 按年切换（按年时把每年最多 12 期汇总）；默认只渲染前 12 行，点「展开全部」最多展开到 600 期（按月）或 100 年（按年），超出上限时给出说明而不会卡死页面。

要点（公式）：

| 量 | 公式 |
|---|---|
| 月利率 | `r = 年利率 ÷ 100 ÷ 12` |
| 等额本息月供 | `M = P·r·(1+r)^n ÷ ((1+r)^n − 1)`；`r = 0` 时退化为 `P ÷ n` |
| 等额本息总利息 | `M·n − P` |
| 等额本金总利息 | `P·r·(n+1) ÷ 2`（等差数列求和，不逐月累加） |
| 等额本金首月 / 递减 | `P÷n + P·r` / `(P÷n)·r` |

边界行为：

| 情况 | 表现 |
|---|---|
| 金额为空 / ≤ 0 / 非法 | 结果全「—」+ 提示「请输入有效的贷款金额（如 100万 或 1000000）」，输入框标红 |
| 期限 > 1200 | 提示「贷款期限最多 1200 期（100 年）」 |
| 期限 ≤ 0 / 非法 | 提示请输入有效期限 |
| 利率为负 / 非法字符 | 提示「年利率不能为负数」/「年利率格式不正确」 |
| 免息（0 或留空） | 正常计算，`总利息 = 0` |
| 末期尾差 | 最后一期剩余本金**强制归零**，不出现 `-0.00` 或 `0.01` 的浮点残差 |

> ⚠ 计算结果为**理论值**：未含手续费、保险、利率浮动、提前还款与 LPR 重定价，签合同前请以银行报价为准。

### 4.3 油耗计算器 · `tools/fuel`

**用途**：两次加油之间算百公里油耗与每公里成本。

| 输入项 | 说明 |
|---|---|
| 加油量（升） | ≥ 0，**允许为 0**（油耗 0）；上限 `1e9` |
| 行驶里程（公里） | 必须 > 0；上限 `1e9` |
| 油价（元/升） | 必须 > 0；**可留空**（留空只算油耗不算钱） |

| 输出 | 单位 |
|---|---|
| 百公里油耗 | L/100km |
| 每公里油费 | 元/km |
| 本次油费 | 元 |
| 每百公里花费 | 元/100km |

要点（公式）：

- `百公里油耗 = 加油量 ÷ 里程 × 100`
- `本次油费 = 加油量 × 油价`
- `每公里成本 = 本次油费 ÷ 里程`
- `每百公里花费 = 百公里油耗 × 油价`

边界行为：

| 情况 | 表现 |
|---|---|
| 里程为空 / ≤ 0 | 三个里程相关指标一起显示「—」，提示「里程需大于 0」；**本次油费仍可算**（只依赖加油量 × 油价） |
| 加油量 = 0 | 合法，油耗为 0 |
| 油价留空 / ≤ 0 | 只显示油耗，费用相关显示「—」，提示「已显示油耗；填写油价后显示费用相关结果」 |
| 输入 > `1e9` | 视为无效（防止天文数字撑坏精度） |
| 派生值溢出（> `1e12`） | 三个里程指标**一起置空**，避免出现「油耗为—但每公里费用有值」的自相矛盾 |

### 4.4 单位换算器 · `tools/convert`

**用途**：长度 / 重量 / 体积 / 温度互换，含市斤与英制。

| 类别 | 基准单位 | 可选单位 |
|---|---|---|
| 长度 | 米 | 毫米、厘米、米、千米、英寸、英尺、英里 |
| 重量 | 千克 | 毫克、克、千克、**斤**、吨、盎司、磅 |
| 体积 | 升 | 毫升、升、立方米、立方厘米、加仑(美)、品脱(美) |
| 温度 | 摄氏度（**偏移型**） | 摄氏度、华氏度、开尔文 |

| 输出 | 说明 |
|---|---|
| 结果 | 换算后的值 + 目标单位名 |
| 换算关系 | `1 <源单位> = ? <目标单位>` |
| 反向关系 | `1 <目标单位> = ? <源单位>` |

要点（公式）：

- **比例型**（长度/重量/体积）：统一换算到类别基准再转出——`结果 = 值 × factor(源) ÷ factor(目标)`。
- **偏移型**（温度）：**绝不按倍率处理**，先归一到摄氏度再转出——`°F = °C × 9/5 + 32`、`K = °C + 273.15`。
- 提供「交换」按钮，一键互换源单位与目标单位。

边界行为：

| 情况 | 表现 |
|---|---|
| 源 = 目标单位 | 直接返回原值，不绕基准单位（规避浮点往返误差） |
| 未输入 / 非法字符 | 结果「—」，提示「输入数值后即时显示换算结果」 |
| `\|值\| > 1e12` | 视为无效，显示「—」 |
| 极大 / 极小值 | 自动切科学计数法（`≥1e12` 或 `<1e-6`），不出现 `Infinity`、不撑破布局 |
| 低于绝对零度 | 仍然给出数值，但结果卡转 `warn` 并提示「低于绝对零度（0 K，-273.15 °C）」 |
| 小数位 | 按量级自适应：0→0 位，≥1000→3 位，≥1→4 位，≥0.001→6 位，其余 8 位，并裁掉尾随 0 |

## 5. 文件存储（WebDAV）配置与使用

### 5.1 为什么必须走后端代理

三个原因（也是 FAQ 里被问最多的）：

1. **CORS**：绝大多数 WebDAV 服务不返回 `Access-Control-Allow-*` 头，浏览器直连会被同源策略直接拦掉。
2. **凭据保护**：放在前端直连意味着跨域请求里带上明文 Basic 认证；走自己的后端，凭据只在「你的浏览器 → 你的服务器」这一段 TLS 里出现。
3. **安全边界可校验**：SSRF 防护、路径边界、超时、体积上限这些事，**只有服务端能做且必须做**。

### 5.2 配置步骤

1. **打开「设置」→「文件存储」**（该区块由 `webdav.js` 提供；模块未加载时自动跳过，不影响其他设置）。
2. **填写连接信息**（三项都是占位符，请替换成你自己的）：

   | 字段 | 示例格式 | 说明 |
   |---|---|---|
   | 服务地址 | `https://<你的域名>/<路径>/` | **必须 https**，且是**目录**（以 `/` 结尾） |
   | 用户名 | `<用户名>` | WebDAV 账号 |
   | 密码 | `<密码>` | 页面内**默认掩码**显示 |

3. **点「测试连接」**：后端向目标地址发一次探测（必要时按层级 MKCOL 创建目录），返回成功或可读的失败原因（网络不通 / 认证失败 / 不是 https / 地址不可达 等）。
4. **点「保存」**：前端用**会话 DEK（AES-GCM）加密**后写入 IndexedDB。**不会**写入 localStorage，更不会以明文落地。
5. **打开侧栏「工具箱」→「文件存储」**（路由 `files`）：浏览目录、上传、下载、新建目录、删除。
6. **不再使用时**：在设置页点「清除」，本地加密凭据立即删除（服务端本就没有留存）。

### 5.3 目录不存在时

**不用手动建**：后端会按路径层级逐级 `MKCOL` 创建，且**幂等**（已存在则跳过，不报错）。所以你可以直接填一个尚不存在的子目录作为根。

## 6. 凭据存储与安全处理（重点）

### 6.1 一句话模型

> 凭据的生命周期是：**你的浏览器内存 →（TLS）→ 你自己的 MedDesk 服务端内存 →（TLS）→ 你的 WebDAV 服务**。
> 中间那一站**用完即弃**：不落盘、不入数据库、不写日志。

### 6.2 存储位置对照

| 环节 | 形态 | 位置 | 是否会长期留存 |
|---|---|---|---|
| 页面表单 | 明文（掩码显示） | 浏览器内存 | 否（刷新即失） |
| 已保存配置 | **AES-GCM 密文**（会话 DEK 加密，`{ivB64, ctB64}`） | **IndexedDB meta 存储**（键名 `webdav.cfg`，经 `MD.db.metaGet/metaSet/metaDel`） | 是（加密态，仅本会话可解） |
| 请求传输 | 明文 | HTTPS **请求体**（不是 URL） | 否 |
| MedDesk 服务端 | 明文 | **仅请求处理期间的内存** | **否**——不落盘、不写日志、不缓存 |
| 目标 WebDAV 服务 | Basic 认证 | 对方服务 | 由对方策略决定 |

**三条硬约束**：

1. **绝不明文存 localStorage**（localStorage 无同源隔离之外的保护，XSS 与扩展程序都能读到；IndexedDB 里至少是密文）。
2. **DEK 不可用时降级为「仅内存」**：拿不到会话 DEK 就不会写盘，界面明确提示用户「凭据仅保存在本次会话，刷新后需重新填写」——**绝不**悄悄降级成明文存储。
3. **凭据不放 URL**：`baseURL / user / pass` 全部走 **JSON 请求体**，避免被 Nginx 访问日志、浏览器历史、Referer、代理日志顺手记下。

### 6.3 服务端安全护栏

| 护栏 | 具体行为 |
|---|---|
| **SSRF 防护** | 仅允许 **https**；拒绝回环地址（`127.0.0.0/8`、`::1`）、私有网段（`10/8`、`172.16/12`、`192.168/16`）、链路本地（`169.254/16`、`fe80::/10`）；**不跟随重定向**（防止「先过校验再跳内网」） |
| **路径边界** | 拒绝 `..`、绝对路径、`\` 反斜杠、空字节、`%2e%2e` 等编码穿越；规范化之后**必须仍在配置根路径内**，否则报错 |
| **凭据不留存** | 不写数据库、不写文件、不进缓存；错误信息脱敏，**日志中绝不出现用户名/密码/完整 URL** |
| **超时** | 单次请求 **15 秒**上限（含连接、发送、读取响应头与响应体） |
| **体积上限** | 下载响应体上限 **200 MiB**；单次列目录最多 **2000** 条；相对路径 ≤ **1024** 字节——超出直接报错，不把超大响应读进内存 |
| **地址格式** | 必须 `https`；**不得内嵌 `user:pass@`**（拒绝，避免凭据写进 URL）；路径缺省时自动补 `/`，后续拼接始终限定在该目录内 |
| **鉴权** | 全部接口要求登录态（与其余 `/api/v1` 一致），错误统一走 `apierr` |

### 6.4 必须知道的能力边界

1. **文件内容不进 E2EE 信封**：文件按原样转发到你的 WebDAV 服务，**不经过 MedDesk 的 DEK 加密**。因此**目标 WebDAV 服务的运营方可以看到文件明文**。需要更强保证时：自己托管 WebDAV 服务，或先在本地加密（如加密压缩包）再上传。
2. **MedDesk 服务端在转发瞬间是能看到内容的**：它必须解密/持有凭据才能代理。这是代理架构的固有代价——所以用「你自己部署的服务」把这一环留在自己手里。
3. **凭据泄露半径 = 该 WebDAV 账号的全部权限**。因此务必用**专用账号 / 应用专用密码**，并把根路径**限定到专门的子目录**，不要用主账号全盘挂载。

### 6.5 用户自查建议

- [ ] 用**专用账号**或**应用专用密码**，不与其它服务复用口令。
- [ ] WebDAV 根路径**限定到子目录**（例如 `https://<你的域名>/<路径>/` 指向一个只放这类文件的目录）。
- [ ] 确认目标地址是 **https**——后端会直接拒绝 http。
- [ ] 定期**轮换密码**，轮换后在设置页重新保存一次。
- [ ] 在共享 / 公共设备上**用完即清除**凭据（设置页「清除」）。
- [ ] 检查你的 Nginx：`access_log` 不要开启记录请求体（`log_format` 里不含 `$request_body`）；MedDesk 自身应用日志不记录请求体。
- [ ] 备份策略照旧：MedDesk 侧不存任何 WebDAV 数据，备份 `backup.sh` 不会包含你的网盘文件。

## 7. `MD.webdav` 接口契约

> 签名以 `web/assets/js/webdav.js` 为准；如与 [CONTRACTS.md](../CONTRACTS.md) 有出入，以契约文档与源码为准。

| 成员 | 签名 | 说明 |
|---|---|---|
| `getConfig()` | `() → Promise<Object\|null>` | 读取配置：内存副本 → IndexedDB 密文（DEK 解密），返回 `{baseURL, user, pass}`；**未解锁或 DEK 已轮换导致解密失败时返回 `null` 且不报错**（视作未配置） |
| `saveConfig(cfg)` | `(cfg) → Promise<{persisted, memoryOnly}>` | 先写入内存（本次会话立即可用），再用会话 DEK 加密落盘；DEK 不可用时 `persisted=false / memoryOnly=true` **降级为仅内存**，由界面提示「仅本次会话有效」 |
| `clearConfig()` | `() → Promise<void>` | 删除 IndexedDB 密文 + 丢弃内存副本；服务端无留存，无需远程清理 |
| `settingsSection()` | `() → HTMLElement` | 返回「设置 → 文件存储」配置卡片（地址/用户名/密码 + 测试连接 + 保存 + 清除）；`app.js` 在模块存在时自动插入，不存在则跳过 |

配套约定：

- 路由：`id='files'`、`title='文件存储'`、`icon='folder'`、`group='工具箱'`、`order=60`（与 `tools` 并列，**不是** `tools/` 子路由）。
- 密码输入默认掩码，不自动填充、不写进任何明文缓存。
- 所有请求走 `MD.api.request`——复用 Bearer 鉴权与 401 自动刷新，请求体统一为 `{baseURL, user, pass, path?}`。
- 事件：保存/清除后经 `MD.bus` 抛出 `webdav:changed`（`{configured, memoryOnly}`）；监听 `auth:changed`，**退出登录或会话失效时立即丢弃内存凭据**，避免用已作废的 DEK 发起请求。

| 方法 | 路径 | 请求体要点 | 说明 |
|---|---|---|---|
| `POST` | `/api/v1/webdav/test` | `{baseURL, user, pass}` | 测试连接（必要时逐级建目录） |
| `POST` | `/api/v1/webdav/list` | `{baseURL, user, pass, path}` | 列目录 |
| `POST` | `/api/v1/webdav/mkdir` | `{baseURL, user, pass, path}` | 新建目录（逐级、幂等） |
| `POST` | `/api/v1/webdav/delete` | `{baseURL, user, pass, path}` | 删除文件或目录 |
| `POST` | `/api/v1/webdav/upload` | `{baseURL, user, pass, path, ...}` | 上传文件 |
| `POST` | `/api/v1/webdav/download` | `{baseURL, user, pass, path}` | 下载文件（有大小上限） |

- **全部需要登录态**，错误响应统一走 `apierr`（`bad_request` / `unauthorized` / `forbidden` / `not_found` …）。

- 服务端护栏：`https` 强制、内网/回环/链路本地拒绝、不跟随重定向、下载 ≤ 200 MiB、列目录 ≤ 2000 条。

## 9. 常见问题（FAQ）

**Q：为什么不能直接从浏览器连我的网盘？**
A：绝大多数 WebDAV 服务不返回 CORS 头，浏览器会直接拒绝跨域请求；而且前端直连会把凭据暴露在跨域请求里。走后端代理还能顺带做 SSRF 与路径边界校验。

**Q：为什么只支持 https 的 WebDAV 地址？**
A：http 的 Basic 认证等于把用户名密码写在明信片上。后端强制 https，同时也是 SSRF 防护的一部分。

**Q：填了一个还不存在的目录会怎样？**
A：会自动创建。后端按层级逐级 `MKCOL`，且幂等——已存在就跳过，不会报错。

**Q：为什么每次刷新/重开浏览器可能要重新填密码？**
A：凭据是用**会话 DEK** 加密后存在 IndexedDB 的。DEK 只属于当前会话，会话结束后旧密文解不开；此时 `saveConfig()` 会返回 `memoryOnly: true`，模块降级为「仅内存」并提示「仅本次会话有效」——**不会**为了省事改成明文存储。重新填一次并保存即可再次加密落盘。

**Q：退出登录后凭据还在吗？**
A：内存副本会被**立即丢弃**；IndexedDB 里的密文仍在该浏览器本地，但**没有会话 DEK 就解不开**。「清除」按钮或「忘记此设备」会把它一并删掉。

**Q：MedDesk 服务器会不会保存我的网盘密码？**
A：不会。不落盘、不入数据库、不写日志、不进缓存；凭据只在处理那一次请求的内存里存在。

**Q：我的文件会被 MedDesk 端到端加密吗？**
A：**不会**。文件按原样转发到你的 WebDAV 服务，不进 E2EE 信封。MedDesk 的 E2EE 保护的是用药等业务记录；文件存储的保密性取决于**你的 WebDAV 服务由谁运营**。敏感文件请先自行加密，或自己托管 WebDAV 服务。

**Q：连接测试失败怎么排查？**
按这个顺序看：① 地址是不是 **https** 且以 `/` 结尾的目录；② 用户名/密码是否正确（注意大小写与空格）；③ 目标服务是否可达（能否在浏览器里打开该地址）；④ 目标服务是否对 MedDesk 服务器 IP 有限流或 IP 白名单；⑤ 证书是否为自签/已过期（后端不信任无效证书）。

**Q：能挂载内网地址吗？**
不能。后端明确拒绝回环、私有网段与链路本地地址，也不跟随重定向——这是防 SSRF 的硬性护栏，不是配置问题。

**Q：计算器会把我的数据传到服务器吗？**
不会。四个工具全部是本地纯计算，没有任何网络请求；改一个数字就重算一次，结果只存在于当前页面。

**Q：大文件上传有上限吗？**
有。下载与列表均有大小上限（防内存打爆），上传还受 Nginx `client_max_body_size` 与 MedDesk 自身体积限制的双层约束。超大文件建议直接用网盘客户端。

## 10. 新增一个工具

与 [EXTENDING.md](EXTENDING.md) 的「加一个模块 = 一个文件 + 一段注册」同构，工具更轻量——**只加一个前端文件**：

1. 新建 `web/assets/js/tool-<id>.js`，结构照抄任一现有工具：
   `输入层（MD.tools.field/select） → 计算层（纯函数，返回 `{...}`） → 渲染层（MD.ui + MD.tools.resultCard）`。
2. 在文件末尾 `MD.tools.register({ id, title, subtitle, icon, category, order, render })`。
3. 在 `web/index.html` 的脚本链里加一行（**必须在 `app.js` 之前、`tools.js` 之后**）。
4. 遵守两条底线：**计算层不碰 DOM**；**不可展示的数值一律输出「—」**。

不需要改后端、不需要改同步层、不需要改侧栏——首页与分类导航会自动收录你的工具。
